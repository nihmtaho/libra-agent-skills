# Onboarding drop-off

## Problem
New workspaces reach the invite step and stop: 62 percent never send one. They
have no one to collaborate with, so the product looks empty and they leave.

## Options considered
1. Pre-fill a demo workspace — cost: a day; assumes: an empty product is the reason.
2. Ask for invites during sign-up — cost: two days; assumes: intent exists at sign-up.
3. Send the invite from the owner's own mailbox — cost: a week; assumes: trust in the sender is the blocker.
4. Remove the invite step and let members join by link — cost: three days; assumes: admins accept link access.
5. Show what a populated workspace looks like — cost: two days; assumes: seeing value beats doing a step.
6. Do nothing and measure for a week — cost: none; assumes: the number is noise.

## Chosen direction
Option 3: the invite arrives from a person the recipient knows, which removes the
"who is this" doubt. The runner-up is option 4, and it wins if admins reject
per-sender mail in the first five interviews.

## Riskiest assumption
That recipients open mail from an unfamiliar product name at all. If they do not,
the direction fails before any UI matters.

## Cheapest test
Ask five admins to send one real invite each this week and count opens. Under two
opens out of five changes the direction.
